ESCALA 1:1 · REV 1.0

Cómo leer esta guía

Este manual reúne la identidad visual de iAR —Industrial Augmented Reality S.L.— bajo una única marca clara y coherente, pensada tanto para entornos industriales como para soluciones digitales y de inteligencia artificial.

Está redactado de forma directa para que cualquier persona del equipo, colaborador o proveedor pueda consultarlo y aplicar la marca con facilidad en presentaciones, documentos o interfaces.

  • 01Cada apartado se presenta como una lámina visual con ejemplos prácticos listos para usar.
  • 02Los colores y códigos pueden copiarse con un clic para llevarlos a cualquier herramienta.
  • 03El botón superior permite alternar entre modo claro y modo oscuro para ver cómo se adapta toda la identidad.

LÁMINA 01/08

Marca única y arquitectura

REV 1.0

Toda nuestra actividad comercial, técnica y de producto se centraliza bajo una sola marca: iAR. No utilizamos submarcas ni logotipos distintos para cada línea o solución. Ya sea en una plataforma de inteligencia artificial, en una aplicación móvil de planta o en una propuesta comercial, la firma es siempre iAR acompañada de un descriptor claro del área o servicio.

  • 01.3Los sellos de certificaciones y partners (como Microsoft Partner o Pyme Innovadora) se sitúan respetando el margen de seguridad y siempre con sus archivos oficiales.

LÁMINA 02/08

Logotipo: construcción y versiones

ESCALA 1:1 · REV 1.0

Tamaños mínimos

Por debajo del mínimo, el logotipo completo pierde la cruz del isotipo: se usa solo el isotipo, nunca el conjunto reducido. Reproducción a una tinta en impresión: versión monocroma.

Sobre fotografía y aplicaciones

  • 02.1Sobre fotografía o vídeo: utiliza la versión negativa (blanca) o principal sobre una zona despejada donde se lea con claridad; si el fondo tiene mucho detalle, coloca una pastilla sólida detrás.
  • 02.2En aplicaciones y web: el isotipo (anillo con cruz) se utiliza en barras de navegación, iconos de aplicación y como favicon en el navegador. El logotipo completo se reserva para pantallas de acceso, portadas y documentos.

LÁMINA 03/08

Paleta de color

CLARO / OSCURO · REV 1.0

Nuestra paleta parte del teal corporativo #05677F, acompañado de grises fríos muy limpios. Para enriquecer presentaciones, gráficos y paneles sin perder sobriedad, sumamos un azul turquesa de acento #22C0B4 y un color complementario cálido #D96B27 para usos puntuales.

Colores de estado y apoyo: significado claro en cualquier pantalla
ColorTono principalFondo suaveCuándo utilizarlo
Éxito#1A7F4E#E9F5EEProcesos completados, equipos operativos y confirmaciones
Aviso#E8A013#FDF3DDAdvertencias preventivas, stock bajo o revisiones pendientes
Error#B3261E#FBEAE8Paradas de línea, incidencias críticas o acciones de borrado

Complementario#D96B27#FDF1E8Contraste en gráficas comparativas e hitos puntuales

Recomendaciones prácticas

  • 03.1Proporción equilibrada: el teal corporativo y los fondos neutros deben dominar la composición; el azul de acento (#22C0B4) y el complementario (#D96B27) se usan en pequeños toques para dirigir la mirada.
  • 03.2Nunca solo color: acompaña siempre los estados (éxito, aviso, error) con un icono y una palabra clara para que cualquier persona lo entienda de un vistazo.
  • 03.3Fondos suaves para avisos: utiliza los tonos suaves de fondo en cajas de alerta y deja los colores intensos para etiquetas pequeñas, botones o iconos.
